# UI Primitives

This directory contains the shared UI building blocks used across the app.

## Purpose

Use these primitives instead of raw ad hoc markup when you need: cards, dialogs, menus, inputs, tabs, or feedback surfaces. This keeps the app visually consistent and reduces repeated patterns.

## Core primitive groups

- Surfaces: Card, Panel, Layout shells
- Overlays: Dialog, Modal, popover-style surfaces
- Form controls: Button, Input, Select, Switch, Tabs
- Feedback: Badge, Alert, Toast, Loading states
- Navigation: Dropdowns, menus, trigger patterns

## Rule of thumb

Prefer composing existing primitives over adding one-off styling or custom wrappers.
